# 发布说明(维护者用)

这一页是给发版的人看的。用户侧的下载/前置条件写在 [安装与更新.md](安装与更新.md),不要在 Release 里重复长篇解释,放链接即可。

## 发布资产

每个 Release **只附一个文件**:

```
MpvSettings.exe
```

- 从 `dotnet publish -c Release -r win-x64 -o publish` 的产物里取,单文件、框架依赖,约 480 KB。
- 不附 mpv 本体、DLL、配置模板、zip 整合包。理由见 [安装与更新.md](安装与更新.md) 的"为什么不打包 mpv"。
- 源码资产由 GitHub 自动打包,不用手动上传。

不要把 `portable_config`、`mpv.exe`、注册表脚本加进 Release——这个工具是覆盖进已有 MyMPC 环境用的。

## tag 规范

```
v1.0.5       正式版
v1.0.5-rc1   候选版(可选)
```

Tag 对应 `csproj` 里的版本号(`1.0.5.0`),不要出现 tag 和程序版本不一致的情况。

## 发布前检查清单

1. `csproj` 版本号、tag、改动记录三处一致。
2. `dotnet build -c Release` 零错误。
3. 编译产物三处哈希一致(发布目录 / 开发包 / 生产环境),确认没拿错旧 EXE。
4. 全新配置目录跑 `--default --dry-run`,检查写计划符合本版默认。
5. 用户文档里提到版本/默认值的地方同步更新。
6. `docs/development/` 里新增的改动记录已脱敏(不放本机绝对路径、测试片名)。
7. Release 正文里的 MyMPC 整包下载入口(国内网盘)仍指向有效链接;本项目的 GitHub 附件只有 `MpvSettings.exe` 单文件,别混。

### 前置条件
已装 MyMPC 且安装时勾选了 MPV 组件。本工具按注册表定位配置,不能脱离 MyMPC 独立使用。详见 [安装与更新](https://github.com/louissgd/MpvSettings/blob/main/docs/安装与更新.md)。

把 MpvSettings.exe 覆盖到 `<安装根>\MediaPlayer\mpv\MpvSettings.exe`。设置存在 portable_config 里,覆盖 EXE 不会丢配置。

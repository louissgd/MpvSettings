# 安装与更新

MpvSettings 是 **MyMPC 的配套设置工具**,不是能独立运行的通用 mpv 设置器。它按 MyMPC 的安装布局定位配置,脱离这个环境会直接禁用。下载前请先读完这一页。

## 前置条件(缺一不可)

程序启动时按下面三步找配置,任何一步不满足,窗口会显示禁用原因而不是设置项:

| # | 条件 | 程序怎么找 |
|---|---|---|
| 1 | 已安装 MyMPC 主程序 | 读注册表 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\App Paths\mplayerl.exe` 的 `Path` 值(64 位视图),作为安装根目录 |
| 2 | 安装时勾选了 MPV 组件 | 检查 `<安装根>\MediaPlayer\mpv\mpv.exe` 是否存在。MyMPC 里 MPV 是选装,没勾就直接禁用,不回退到别处 |
| 3 | mpv 配置已建立 | 检查 `<安装根>\MediaPlayer\mpv\portable_config\mpv.conf` 是否存在。首次安装由 MyMPC 安装程序或 `MpvSettings.exe --default` 生成 |

三条都满足,配置目录就锚死在 `<安装根>\MediaPlayer\mpv\portable_config`。程序**不会**把 EXE 旁边碰巧存在的 `portable_config` 当生产配置来写——这是故意的,防止误写。

程序左下角"当前配置"会显示实际读到的配置来源和完整路径,可以先看一眼再改。

## 下载

分两步,别搞混:**网盘下的是 MyMPC 整包,GitHub 下的是本工具的单 EXE。**

下面是 **MyMPC 整包**(主程序 + MPV + 配置)的下载渠道,不是 MpvSettings 单独的文件。安装时记得勾选 MPV 组件,否则本工具会禁用。

|---|---|---|---|
| **123云盘(推荐)** | https://www.123pan.com/s/iF8iVv-Xbeh3.html | `mnCb` | 无需登录、不限速,网页直接下载 |
| 电信天翼云盘(备用) | https://cloud.189.cn/t/AbieUzNzyqUf | `s4lr` | 备用渠道 |

这三个是 MyMPC 整包的**固定链接**:MyMPC 更新时只换链接里的内容,链接和提取码不变。

### 第二步:MpvSettings.exe(更新用)

从 [GitHub Releases](https://github.com/louissgd/MpvSettings/releases/latest) 下载 `MpvSettings.exe` 单文件。MyMPC 整包里已经带了一份,这里只用于单独更新到最新版。海外用户或需要校验哈希的也用这个渠道。

本工具的 Releases **只提供这一个 EXE**,不打包 mpv、不提供整合包。原因见下面"为什么不打包 mpv"。

运行要求:

- Windows 10 / 11 x86-64
- .NET 10 桌面运行时(`SelfContained=false`,单文件但不自带运行时)。已装 .NET 10 SDK 的机器自带;否则装运行时即可,约几十 MB
- 上面三条件成立(即已经有一套能正常播放的 MyMPC + MPV)

## 安装 / 更新

只有一步:**把下载的 `MpvSettings.exe` 覆盖到 MyMPC 的 mpv 目录**。

```
<安装根>\MediaPlayer\mpv\MpvSettings.exe
```

`<安装根>` 就是注册表 `App Paths\mplayerl.exe` 的 `Path` 值,通常在系统程序安装目录下的 MyMPC 文件夹。覆盖后直接双击运行,不需要注册表注册、不需要管理员权限(除非安装目录本身受 UAC 保护)。

首次进入一个全新配置目录时,可以先跑一次:

```bat
MpvSettings.exe --default
```

无窗口地把出厂默认写进配置并探测本机字体,退出码 0 即成功。这也正是 MyMPC 安装程序调用的方式。

更新时直接覆盖 EXE 即可,设置都在 `portable_config` 里,不在 EXE 里,不会丢。

## 为什么不打包 mpv

不是省事不省事的问题,是打包了也没用:

- **路径检查锚在注册表,不在 EXE 旁边**。就算把 mpv 塞进同一个压缩包,解压到任意目录双击,程序仍然读 `mplayerl.exe` 的 `Path`,仍然要求 `<Path>\MediaPlayer\mpv\mpv.exe`。解压位置不对照旧禁用。
- **本程序只负责写配置**,不启动、不解码、不带播放器逻辑。左下角"打开 MPV 播放器"只是拉起已经装好的 `mpv.exe`。
- mpv 主程序约 100 MB,外加 DLL、脚本、配置模板,体积和分发许可(GPL/LGPL)都是另一件事,和这个设置工具无关。

也就是说,单文件发布不是"缺了东西",而是这个工具本来就该装进一套已有的 MyMPC 里。

## 常见禁用提示

| 窗口提示 | 原因 | 处理 |
|---|---|---|
| 未找到 mpv 配置目录(App Paths 注册表无记录,且未在 EXE 附近找到 portable_config) | 没装 MyMPC 主程序,注册表读不到 `mplayerl.exe` | 先装 MyMPC;本工具不能脱离它独立使用 |
| 未安装 MPV(找不到 `...\mpv.exe`),设置已禁用 | 装了 MyMPC 但安装时没勾 MPV 组件 | 重新运行 MyMPC 安装程序勾上 MPV |
| 未安装 MPV(找不到 mpv.exe),设置已禁用 | 配置目录找到了,但旁边的 mpv.exe 不在预期位置 | 检查 MyMPC 的 mpv 是否被移动或删掉 |
| 缺少 mpv.conf,设置已禁用 | 配置目录存在但没有 mpv.conf | 跑 `MpvSettings.exe --default` 生成,或重装 MyMPC |

## 给谁用

- **要装 MyMPC 的人**:本工具随 MyMPC 环境使用,按上面覆盖 EXE 即可。
- **只用独立 mpv、不带 MyMPC 的人**:本工具不适用,不会为你开放路径检查。请直接编辑 `mpv.conf`,或选择面向通用 mpv 的其它设置器。这不是功能缺失,是定位如此。

# 快捷键

快捷键页管理 `input.conf` 里本程序认识的那些绑定。分五组。

## 语义

- **改键只叠加不撤销**。给一个动作设新键 = 写一行强绑定,原来的默认弱绑定仍然可用(mpv 的弱绑定删不掉)。
- **清空 = 恢复默认**。把一个"自定义"行清掉 = 删掉那一行强绑定,回到 mpv 默认。这不是"禁用按键"。
- **默认态 / 留空态清空 = 无操作**。本来就没写行的,清不掉也没必要清。
- **ShipLine 行随"恢复默认"写回**。本包发行键(见 E2/E4 组)会随恢复默认一起写回 `input.conf`,不会被清掉。
- **改完重启生效**。mpv 启动后不重读 `input.conf`。

键名大小写敏感:`s` 和 `S` 是两个键;`#` 键必须写成 `SHARP`。命令里的数值写法(`1.0` vs `1`)程序会归一化再比对,不会因为格式差异误判改动。

## E1 · 播放控制

| 动作 | 默认键 | 命令 |
|---|---|---|
| 播放 / 暂停 | SPACE | `cycle pause`(另有 p 键) |
| 停止 / 退出 | q | `quit` |
| 上一个 / 下一个文件 | `<` / `>` | `playlist-prev` / `playlist-next` |
| 快退 / 快进 5 秒 | LEFT / RIGHT | `seek -5` / `seek 5` |
| 快退 / 快进 60 秒 | DOWN / UP | `seek -60` / `seek 60` |
| 逐帧前进 | `.` | `frame-step` |

| 全屏切换 | Alt+ENTER | 本包把默认从 f 改过来;f 仍可用,ESC 退出全屏不变 |
| 退出全屏 | ESC | — |
| 截图(含字幕) | s | — |
| 截图(不含字幕) | S | — |

| 显示进度 | o | — |

## E5 · 留空可自设

这些 mpv 没有默认绑定或已被占用,页面留空给你自己设:

| 动作 | 说明 |
|---|---|
| 显示播放列表 | 原默认 F8 被占用;右键菜单仍可打开 |
| 停止播放(保留列表) | — |
| 快进 10 秒 | 默认只有 5 / 60 秒 |
| 快退 10 秒 | 同上 |

## 冲突处理

同一键绑到两个动作会拦下来,不允许写盘。程序按规范命令串匹配行,数值写法差异先归一化,避免误判。

更多默认键的全表(mpv 内置弱绑定 + 本包强绑定)见 [development/MPV快捷键_默认绑定全表.md](development/MPV快捷键_默认绑定全表.md)。

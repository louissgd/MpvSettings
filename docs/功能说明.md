# 功能说明

MpvSettings 有五个设置页和一个字幕样式弹窗。所有页面共用一个"草稿"——打开窗口时从磁盘读出当前值,你改的是草稿,点"应用"或"确定"才写盘。

## 通用约定

- **应用 vs 确定**:"应用"写盘但保持窗口开着;"确定"写盘并关闭;"取消"或 ✕ 直接丢弃草稿。
- **重启生效**:mpv 启动后不监视配置文件。写完设置要重启播放器才生效。左下角"打开 MPV 播放器"会拉起播放器。
- **自定义值置灰**:盘上出现程序预设之外的值,下拉框会追加一个"自定义"项并选中,同时置灰禁止写入。这是防止误覆盖你看不懂或手工写的值。想让程序接管,先选一个预设值。
- **只写 diff**:保存时只写你改过的键,没动的一个字节不改。导入/恢复默认除外(那是有意的整组覆盖)。

## 播放页

| 设置 | 写盘键 | 说明 |
|---|---|---|
| 硬解方式 | `hwdec` | auto-copy(推荐,杜比视界/HDR)、auto-safe、auto、d3d11va、nvdec、no |
| 隔行扫描 | `deinterlace` | 开/关 |
| 循环播放 | `loop-file` | 开/关 |
| 记忆播放位置 | `save-position-on-quit` | 开/关 |
| 字幕匹配系统语言 | `subs-match-os-language` | 开/关 |
| 仅强制字幕回退 | `subs-fallback-forced` | 开/关 |
| 外挂字幕自动重读 | `script-opts/MyMPC.conf: sub_autoreload` | 字幕文件改动后自动重载,靠内嵌 Lua 轮询实现 |
| 底部进度条 | `script-opts/MyMPC.conf: osd_progress` | 播放时窗口底部一条细横线游标(透明轨道,主题绿),随进度移动,窗口/全屏都显示;默认开,纯音频无封面时不显示(信息窗自带进度条)。改动需重启播放器生效 |
| 封面原始尺寸 | 封面配置 | 保持封面原始大小 |
| 封面大小上限 | 封面配置 | 默认 1200 px |
| 无封面 UI | 封面配置 | 无封面时不显示占位 UI |
| 窗口比例 | 封面配置 | 默认 90% |
| 多实例 | 封面配置 | 允许/禁止多个播放器实例 |

页面底部有"SRT 默认样式 · 打开设置"按钮,见 [字幕样式.md](字幕样式.md)。

## 画面页

| 设置 | 写盘位置 | 说明 |
|---|---|---|
| HDR 模式 | HDR 自动切换脚本 | 直通显示器(默认)/ HDR 转 SDR |
| 色调修复档位 | `tone-mapping` 等 | 关闭(默认)/ 0.6 / 0.8 / 1.0 |
| 色域范围 | `video-output-levels` | PC 0–255(默认)/ TV 16–235 |
| NVIDIA VSR | `script-opts/MyMPC.conf` + Lua | 视频超分辨率,受驱动和片源分辨率前提限制 |
| VSR 分辨率上限 | 同上 | ≤480p / 720p / 1080p / 1440p |
| NVIDIA HDR | 同上 | RTX HDR,峰值亮度 400–2000 nit 可选 |

VSR / HDR 开关有**硬件前提**:NVIDIA App 未关、驱动不支持、Windows HDR 关等情况下会自动置灰并写 `no`,旁边文字说明原因。前提不满足时强行开只会崩溃,所以程序直接挡住。

色调修复档位只在你明确选了 HDR→SDR 时才可写;直通模式下强制关闭。两个控件共用一个 `tone-mapping` 键,由最终状态反推,避免互相打架。

## 音频页

| 设置 | 说明 |
|---|---|
| 音效滤镜(常驻) | 专属音效滤镜始终启用,不受音效总开关、导出导入、恢复默认影响;你自己加的其它滤镜也保留 |
| 声道输出 | auto(默认)/ auto-safe / stereo / mono |
| 比特流直通 | AC-3、E-AC-3、TrueHD、DTS 等源码直通;无兼容设备时置灰并说明原因 |

## 截图页

| 设置 | 写盘键 | 说明 |
|---|---|---|
| 保存位置 | `screenshot-dir` | 桌面 / 图片文件夹 / mpv 目录 / 自填绝对路径 |
| 文件名模板 | `screenshot-template` | 默认带时间码 |
| 图片格式 | `screenshot-format` | JPG(默认)/ PNG |

WebP / AVIF / JXL 不提供——对应编码库已从 mpv 构建中裁掉,选了只会写坏配置。

## 配置备份 / 恢复(关于页)

- **导出**:把当前设置原样存进备份文件夹,覆盖上一次备份(固定只保留一份)。
- **导入**:先检查备份文件完整性,有一处对不上就中止、不改当前配置;通过则先自动把当前配置另存到 `_before_import`,再写回。只覆盖本程序管理的键,你自己加的快捷键和菜单条目保留。第三方脚本和截图保存位置不参与备份。
- **更改/打开文件夹**:默认 `桌面\MyMPC-MPV-备份`,选过的文件夹会记住。

## 当前配置(只读,关于页)

显示配置来源、mpv 程序路径、读取时间、音效状态、比特流直通状态。用来确认程序读的是哪份配置——多 mpv 环境时尤其有用。

## 恢复默认

- 界面:设置页顶部的"恢复默认/重置本页"按钮,只改草稿,仍需点确定写盘。
- 命令行:`MpvSettings.exe --default`,无窗口直接写盘,退出码即结果。安装程序和脚本用这个。

注意"恢复默认"会把用户手工标定的值也归位——这是恢复默认的定义。截图保存位置是例外:恢复前先取出,恢复后原样写回,不把它挪回桌面。

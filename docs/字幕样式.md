# SRT 默认字幕样式

播放页底部的"SRT 默认样式 · 打开设置"按钮打开一个独立窗口,调的是 mpv 的 `--sub-*` 系列选项。

## 作用范围(重要)

这个面板**只影响纯文本字幕**(SRT、ASS 转换来的内部字幕等),**不影响 ASS/SSA 作者样式和 SUP/PGS 位图字幕**。

原理:

- SRT 等纯文本字幕被 mpv 转成内部 ASS 格式(`converted=true`),`--sub-*` 覆盖对它生效。
- ASS/SSA 原生字幕 `converted=false`,设了 `sub-ass-override=no` 后完全走作者参数,不吃任何 `--sub-*` 覆盖。
- SUP/PGS 是位图字幕,根本不走文本渲染,任何文本样式都影响不到它。

面板里"保护 ASS 特效字幕作者样式"开关默认开,对应 `sub-ass-override=no`。关掉它会变成 `scale`,届时 ASS 也会被套上统一样式——只有当你想用 mpv 的样式去"救"一个排版烂的 ASS 时才关。

## 可调项

| 项目 | 写盘键 | 出厂默认 | 说明 |
|---|---|---|---|
| 字体 | `sub-font` | Microsoft YaHei | 只读展示 + 按钮打开系统字体对话框;有华文楷体时 `--default` 会升级成 STKaiti |
| 颜色 | `sub-color` | `#FFFFFFFF`(纯白) | 色块点开系统调色板;文本框也可手输 `#AARRGGBB` |
| 字号 | `sub-font-size` | 48 | 基于 PlayResY=720;华文楷体习惯 52 |
| 行间距 | `sub-line-spacing` | 0 | 负值收紧双行字幕间距 |
| 粗体 / 斜体 | `sub-bold` / `sub-italic` | no | 跟随字体对话框里选的字形 |
| 描边宽度 | `sub-outline-size` | 1 | ASS 常用值;0 为无描边 |
| 阴影偏移 | `sub-shadow-offset` | 0 | 0 为无阴影 |
| 左右边距 | `sub-margin-x` | 19 | — |
| 底部边距 | `sub-margin-y` | 34 | — |

弹窗里的"完成"按钮**直接写盘**,不用再回主界面点应用/确定。"取消"撤销本次在弹窗里的全部改动。

## 字号换算

字体对话框里的"大小"按 ASS 脚本 PlayResY=1080 的点数填(72 → 48、78 → 52),程序自动换算到 mpv 的 720p 基准。下方字号滑杆显示的是换算后的 720p 值。所以:

```
mpv 字号 = 点数 × 720 / 1080 = 点数 × 2/3
```

别用屏幕 DPI 去换算——那是另一回事,会得出错误的大字号。

## 颜色格式

两套格式别混:

| 场景 | 格式 | 例子 |
|---|---|---|
| 本程序 UI / mpv.conf 的 `--sub-color` | `#AARRGGBB`(RGB 序,AA 正常) | `#FFFFFFFF` |
| ASS 字幕文件内部 | `&HAABBGGRR`(BGR 序,AA 反向) | `&H00FFFFFF` |

mpv 用 `MP_ASS_COLOR` 宏在内部转换。本程序统一用 `#AARRGGBB`。

**写盘坑**:`mpv.conf` 里 `#` 是注释符,`sub-color=#FFFFFFFF` 会被整行忽略,颜色回落到白色。所以带 `#` 的值必须加引号写:`sub-color='#FFFFFFFF'`。程序自动处理。

## 不提供的项

字符集、OpenType 语言、角度 z、ScaleX / ScaleY 等特效字段 mpv 没有原生独立选项,本面板不提供。需要复杂特效就直接用 ASS 字幕,让作者参数决定。

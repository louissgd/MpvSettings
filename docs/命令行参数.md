# 命令行参数

所有命令行入口都在建窗之前处理——**无窗口、无对话框,退出码即结果**。给安装程序、AHK 脚本和自动化用。

## 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功(包括"磁盘已是目标值、未重写") |
| `1` | 写入被阻止或失败 |
| `2` | 配置目录不可用 / 参数冲突 / 清单无效 |

## 通用参数

| 参数 | 说明 |
|---|---|
| `--config-dir=<目录>` | 显式指定 `portable_config` 目录,覆盖注册表定位。也支持 `--config-dir <目录>` 写法。验证和多环境时用 |
| `--dry-run` | 只计算写计划、打印出来,不写盘 |
| `--keep-registry` | 不写注册表项(只改配置文件) |
| `--dump-plan=<文件>` | 把写计划导出成 JSON(调试用) |
| `--dump-result=<文件>` | 把写结果导出成 JSON(调试用) |

`--dump-*` 只写你显式指定的文件,绝不碰配置目录。不带这些参数时程序一个额外字节都不写。

## 恢复默认

```bat
MpvSettings.exe --default
```

别名:`-default`、`/default`(大小写不敏感)。

把所有设置恢复为程序内置出厂值,无窗口。字体有探测逻辑:本机装了华文楷体(`STKaiti`)就把 SRT 默认字体升级成华文楷体 / 52,否则用微软雅黑 / 48。颜色固定纯白。

```bat
MpvSettings.exe --default --dry-run          :: 只看会改什么,不写
MpvSettings.exe --default --config-dir="D:\临时\portable_config"
```

## 导出配置

```bat
MpvSettings.exe --export[=<目录>]
```

别名:`-export`。不写目录时用"记住的文件夹",首次为 `桌面\MyMPC-MPV-备份`。

| 附加参数 | 说明 |
|---|---|
| `--include-extra` | 连第三方脚本等额外文件一起导出 |

## 导入配置

```bat
MpvSettings.exe --import[=<目录>] [--dry-run] [--keep-registry] [--include-extra] [--no-snapshot]
```

别名:`-import`。

| 附加参数 | 说明 |
|---|---|
| `--dry-run` | 只校验清单、打印计划,不写盘 |
| `--keep-registry` | 不还原注册表项 |
| `--include-extra` | 连额外文件一起导入 |
| `--no-snapshot` | 导入前不自动另存当前配置(默认会存到 `_before_import`) |

导入前会校验清单完整性,有一处对不上就中止、退出码非 0、当前配置不动。

`--export` 和 `--import` 不能同时给,同时给返回 2。

## 内部/调试参数

这些是开发验证用的,正常用户不需要:

| 参数 | 说明 |
|---|---|
| `--dump-only` | 只把反推后的草稿导出,不建窗口、不写盘 |
| `--apply-only` | 按草稿写盘,不建窗口 |
| `--plan-only` | 只输出写计划,不建窗口 |

## 一个注意点

程序是 WinExe(无控制台),从 cmd 运行时会借用父进程的控制台输出。输出文字用 UTF-8 编码,而中文版 cmd 默认代码页是 GBK,所以直接在 cmd 里看可能是乱码。**这不影响功能**——写盘结果看退出码,或用 `--dump-result` 导出 JSON 看结构化结果。需要可读输出时,先执行 `chcp 65001` 把控制台切成 UTF-8。
